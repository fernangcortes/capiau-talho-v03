# 17. Roadmap e Guia de Contribuição

O **CapIAu-Talho** é um projeto de código aberto sob a licença **GPL v3**, mantido pela comunidade de realizadores audiovisuais e desenvolvedores de software livre.

---

## 🗺️ Roadmap de Desenvolvimento

O planejamento detalhado está em `docs/planos/PLANO_SUITE_NLE_CLASSICO.md` (suíte NLE) e `docs/planos/ORDEM_DE_IMPLEMENTACAO.md` (ordem de todos os planos, em ondas). Esta página resume o estado.

### Entregue
- Timeline multipista em Canvas 2D com pistas de vídeo, áudio e texto.
- Suíte NLE clássica, Tasks 0 a 18: ferramentas de edição de precisão (lâmina, slip, slide, rolling, rate stretch, mão e zoom), colisão e ripple, montagem de 3 e 4 pontos, Match Frame, Replace Edit, subclipes, timecode interativo, freeze frame, velocidade por clipe, crossfade de áudio, transições de vídeo, camada de ajuste e cor sólida.
- **Task 23: trava total de pista** (cadeado, `Shift+L` na pista ativa e `Ctrl+Alt+Shift+L` em todas).
- **Task 24: margens de segurança e máscaras de proporção** no Program Player (`Ctrl+Shift+G` e `Ctrl+Alt+G`).
- Camada de detecção facial no Source Player (`Ctrl+Alt+B`, espiar com `Alt`).
- Diálogos de confirmação próprios (janelas NLE com suporte a vários monitores).
- Transcrição palavra a palavra, diarização, Gaveta de Pistas, biometria facial local com DBSCAN.
- Diagnóstico de áudio, tratamento renderizado, denoise local (DPDFNet/GTCRN) e Auphonic opcional.
- Exportação OTIO, XML (FCP7) e EDL, legendas e render de vídeo com paridade com o player.

Contribuições de código, correção de bugs, documentação e sugestões de novos recursos são muito bem-vindas!

### Estrutura de Pastas do Projeto

```
capiau-talho-v03/
├── src/
│   ├── api/             # Rotas e controladores FastAPI

└── wiki/                # Documentação oficial da Wiki do GitHub
```

## 🧪 Executando a Suíte de Testes

Antes de enviar qualquer modificação, rode os testes.

### 1. Backend (Python / pytest)
```bash
pip install pytest
python -m pytest tests/ -v
```
A configuração está em `pytest.ini` (testes em `tests/test_*.py`).

### 2. Interface e Timeline (Node.js)
Os autotestes são módulos ESM `tests/autoteste_*.mjs`, executados diretamente com `node`:
```bash
# Um teste específico
node tests/autoteste_match_frame.mjs

# Todos, em sequência
node -e "import fs from 'node:fs'; import { execSync } from 'node:child_process'; const files = fs.readdirSync('tests').filter(f => f.startsWith('autoteste_') && f.endsWith('.mjs')); for (const f of files) { execSync('node tests/' + f, { stdio: 'inherit' }); }"
```

### 3. Verificação da documentação
O script `scripts/verificar_docs.py` confere a documentação contra o código (links, âncoras e blocos gerados). Rode-o antes de abrir um PR que toque em `README.md`, `USER_MANUAL.md`, `wiki/` ou `docs/`. **A confirmar:** o script está sendo criado e pode ainda não existir na sua cópia.

> [!IMPORTANT]
> **As tabelas de atalhos e de rotas da API são geradas a partir do código** (`src/ui/js/keymapService.js` e as rotas do FastAPI). **Não as edite à mão:** o conteúdo entre os marcadores `GERADO:ATALHOS` e `GERADO:API` é sobrescrito pelo gerador. Para mudar um atalho, altere o `keymapService.js`.

## 📝 Padrões de Código e Boas Práticas

1. **Python:** Siga rigorosamente a **PEP 8**, utilize anotações de tipo (*Type Hints*) e mantenha docstrings claras.
2. **Frontend:** Mantenha JavaScript moderno (ES6+) modular sem frameworks pesados para garantir velocidade máxima e carregamento instantâneo.
3. **Tarefas Assíncronas:** Todo processamento longo no backend deve emitir progresso via `TASK_MANAGER` e suportar cancelamento gracioso.
4. **Preservação de Dados:** Nunca modifique os arquivos originais do usuário no disco.
5. **Documentação:** mantenha os documentos em português do Brasil, com tabelas em Markdown (pipes), sem Mermaid, e títulos sem emoji no início.

## 🚀 Como Enviar um Pull Request (PR)

1. Faça um Fork do repositório no GitHub.
2. Crie uma branch para sua funcionalidade: `git checkout -b feature/minha-melhoria`.
3. Faça o commit das suas alterações: `git commit -m "feat: adiciona sincronia de multicâmera por áudio"`.
4. Envie para o seu fork: `git push origin feature/minha-melhoria`.
5. Abra um **Pull Request** detalhando as mudanças realizadas e os testes executados.
