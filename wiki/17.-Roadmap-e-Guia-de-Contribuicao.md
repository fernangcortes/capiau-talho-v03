# 17. Roadmap e Guia de Contribuição

O **CapIAu-Talho** é um projeto de código aberto sob a licença **GPL v3**, mantido pela comunidade de realizadores audiovisuais e desenvolvedores de software livre.

---

## 🗺️ Roadmap de Desenvolvimento

### 🟢 Versão v0.3 (Versão Atual)
- [x] Motor de Timeline Multipista em Canvas 2D com suporte a pistas V1-V3 e A1-A4.
- [x] Suporte a J/L-Cuts nativos e ferramentas de corte (Ripple, Roll, Slip, Slide).
- [x] Transcrição fonética com timestamps palavra por palavra e atalho `Shift+E`.
- [x] Diarização com Gaveta de Pistas e Inspetor de Fala com Waveform.
- [x] Biometria facial 100% local com clustering DBSCAN (InsightFace ONNX).
- [x] Integração de restauração de áudio com DeepFilterNet e Auphonic REST API.
- [x] Gerenciamento de cor OpenColorIO e transformação/recorte interativo no viewport.
- [x] Interoperabilidade com OpenTimelineIO (`.otio`), FCP7 XML e EDL.
- [x] Design System Flat e Seamless com sidebars adaptativas e linhas restauradoras de 4px.

### 🟡 Versão v0.4 (Em Andamento / Próxima)
- [ ] **Sincronização Multicâmera por Áudio:** Alinhamento automático de múltiplas câmeras e gravadores de som direto comparando formas de onda sonoras (Audio Waveform Sync).
- [ ] **Construtor Automático de Storyline:** Geração de propostas de escaleta e estrutura de roteiro a partir de múltiplos depoimentos com LLM.
- [ ] **Inserção Inteligente de Coberturas (Auto B-Roll):** Sugestão automatizada de planos de B-Roll na pista V2 enquanto o entrevistado fala na V1 sobre determinados assuntos.

### 🔵 Versão v0.5+ (Futuro)
- [ ] **Scopes de Vídeo em Tempo Real:** Vectorscope, Waveform RGB e Histograma integrados ao monitor de programa.
- [ ] **Revisão Colaborativa WebRTC:** Geração de links seguros para diretores e clientes assistirem e inserirem notas com timecode pelo navegador em tempo real.

## 💻 Guia de Contribuição

Contribuições de código, correção de bugs, documentação e sugestões de novos recursos são muito bem-vindas!

### Estrutura de Pastas do Projeto

```
capiau-talho-v03/
├── src/
│   ├── api/             # Rotas e controladores FastAPI
│   ├── color/           # Módulos de cor e OpenColorIO
│   ├── core/            # Modelos de dados e lógica central de projeto
│   ├── db/              # Conexões SQLite e repositórios
│   ├── export/          # Exportadores OTIO, XML, EDL e Render FFmpeg
│   ├── ingest/          # Varredura, hashing e geração de proxies
│   ├── media/           # Processamento de vídeo, áudio e fotos
│   ├── nlp/             # Processamento de linguagem natural e agentes
│   ├── search/          # Motores de busca híbrida e ChromaDB
│   ├── transcription/   # Integrações com AssemblyAI e Whisper
│   ├── ui/              # Interface web (HTML5, CSS3, JS, Canvas 2D)
│   └── vision/          # Detecção facial ONNX, PySceneDetect e CLIP
├── tests/               # Suíte de testes unitários e de integração
├── docs/                # Documentos técnicos e especificações
└── wiki/                # Documentação oficial da Wiki do GitHub
```

## 🧪 Executando a Suíte de Testes

Antes de enviar qualquer modificação, certifique-se de que todos os testes automatizados estejam passando:

```bash
# Executar todos os testes
pytest

# Executar com relatório detalhado
pytest tests/ -v -s

# Executar apenas testes de timeline
pytest tests/test_timeline.py -v
```

## 📝 Padrões de Código e Boas Práticas

1. **Python:** Siga rigorosamente a **PEP 8**, utilize anotações de tipo (*Type Hints*) e mantenha docstrings claras.
2. **Frontend:** Mantenha JavaScript moderno (ES6+) modular sem frameworks pesados para garantir velocidade máxima e carregamento instantâneo.
3. **Tarefas Assíncronas:** Todo processamento longo no backend deve emitir progresso via `TASK_MANAGER` e suportar cancelamento gracioso.
4. **Preservação de Dados:** Nunca modifique os arquivos originais do usuário no disco.

## 🚀 Como Enviar um Pull Request (PR)

1. Faça um Fork do repositório no GitHub.
2. Crie uma branch para sua funcionalidade: `git checkout -b feature/minha-melhoria`.
3. Faça o commit das suas alterações: `git commit -m "feat: adiciona sincronia de multicâmera por áudio"`.
4. Envie para o seu fork: `git push origin feature/minha-melhoria`.
5. Abra um **Pull Request** detalhando as mudanças realizadas e os testes executados.
