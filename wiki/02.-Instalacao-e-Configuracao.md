# 02. Instalação e Configuração

Este guia detalha o processo de instalação do **CapIAu-Talho** no Windows e Linux, além de explicar todas as opções de configuração do arquivo `.env` e a criação do inicializador silencioso.

---

## 💻 Requisitos de Sistema

O CapIAu-Talho foi otimizado para rodar em hardware convencional com foco em CPU:

| Componente | Mínimo | Recomendado |
| :--- | :--- | :--- |
| **Processador (CPU)** | 4 núcleos (Intel Core i5 8ª Geração / AMD Ryzen 5) | 8 núcleos ou mais (Intel Core i7/i9 ou AMD Ryzen 7/9) |
| **Memória RAM** | 8 GB RAM | 16 GB a 32 GB RAM |
| **Armazenamento** | 5 GB livres para o software + espaço para proxies | SSD NVMe para cache de proxies |
| **Placa de Vídeo (GPU)** | Não obrigatória (CPU First) | Opcional: NVIDIA CUDA para acelerar Whisper/CLIP |
| **Sistema Operacional** | Windows 10/11 (64-bit) ou Linux (Ubuntu 20.04+) | Windows 11 / Ubuntu 22.04 LTS |
| **Ferramentas Externas** | **FFmpeg 5.0+** e **FFprobe** instalados no PATH | FFmpeg 6.0+ |

---

## 🛠️ Instalação Passo a Passo

### Passo 1: Clonar o Repositório

```bash
git clone https://github.com/fernangcortes/capiau-talho-v03.git
cd capiau-talho-v03
```

### Passo 2: Criar e Ativar o Ambiente Virtual Python

Recomendamos utilizar o **Python 3.10 ou 3.11**:

**No Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**No Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Passo 3: Instalar as Dependências

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Passo 4: Verificar o FFmpeg no Sistema

Certifique-se de que o executável `ffmpeg` e `ffprobe` estejam no PATH do sistema:

```bash
ffmpeg -version
ffprobe -version
```

> [!TIP]
> No Windows, você pode instalar o FFmpeg facilmente usando o Winget: `winget install Gyan.FFmpeg`.

## ⚙️ Configuração do Arquivo `.env`

Crie uma cópia do arquivo de exemplo `.env.example` nomeando-o como `.env`:

```bash
cp .env.example .env
```

### Principais Variáveis de Configuração

#### 1. Chaves de APIs de Inteligência Artificial
```env
# Transcrição ASR (AssemblyAI ou OpenAI/Groq)
ASSEMBLYAI_API_KEY=sua_chave_aqui
OPENAI_API_KEY=sua_chave_aqui
GROQ_API_KEY=sua_chave_aqui
GEMINI_API_KEY=sua_chave_aqui

# Restauração Profissional de Áudio (Auphonic Cloud)
AUPHONIC_USER=seu_usuario_auphonic
AUPHONIC_PASSWORD=sua_senha_auphonic

# Provedores Locais (Ollama / LocalAI)
OLLAMA_BASE_URL=http://localhost:11434
```

#### 2. Configurações de Hardware e Aceleradores
```env
# Dispositivo de execução para modelos locais (cpu / cuda / directml)
DEVICE=cpu

# Modo de Transcrição Padrão: assemblyai | whisper_local | whisper_groq | whisper_api
TRANSCRIPTION_PROVIDER=assemblyai

# Modelo Whisper Local (tiny, base, small, medium, large-v3)
WHISPER_LOCAL_MODEL=base
```

#### 3. Diretórios de Trabalho e Mídias
```env
# Diretório monitorado para ingestão
WATCH_DIR=watch

# Diretório de armazenamento de dados e proxies
DATA_DIR=data
PROXIES_DIR=data/proxies
EXPORTS_DIR=data/exports
DB_PATH=data/capiau.db
```

## 🚀 Executando o CapIAu-Talho

### Modo Desenvolvimento (com recarregamento automático):

```bash
uvicorn src.api.main:app --host 127.0.0.1 --port 8000 --reload
```

Abra o seu navegador no endereço: **`http://localhost:8000`**.

---

## 🖥️ Inicializador Silencioso para Windows (Desktop Launcher)

Para abrir o CapIAu-Talho no Windows sem manter uma janela preta do Prompt de Comando (CMD) aberta:

1. Execute o script `criar-atalho.bat` na raiz do projeto.
2. O script criará o atalho **`CapIAu.lnk`** na sua Área de Trabalho.
3. O atalho utiliza `pythonw.exe` em segundo plano para subir a API FastAPI e abre automaticamente a janela do navegador.

---

## 🐳 Executando com Docker & Docker Compose

Para rodar em um ambiente isolado conteinerizado:

```bash
docker-compose up -d --build
```

O dashboard estará disponível em `http://localhost:8000`, montando os volumes locais `watch/` e `data/` para preservação dos seus arquivos e bancos de dados.
