# 02. Instalação e Configuração

Este guia leva o **CapIAu-Talho** do repositório recém-clonado até a interface aberta no navegador. Cobre Docker, instalação local (Windows e Linux/macOS), dependências opcionais e o arquivo `.env`.

> [!WARNING]
> **Segurança.** Hoje o servidor não tem autenticação, aceita requisições de qualquer origem (CORS `*`) e escuta na porta 8000. Existe um plano de autenticação e restrição de rede, ainda não implementado. Use o programa **apenas em máquina ou rede confiável** e não exponha a porta 8000 na internet.

## Requisitos

| Item | Mínimo | Recomendado | Observações |
| :--- | :--- | :--- | :--- |
| **Python** | 3.12 (usado na imagem Docker) | 3.12 | Versões anteriores à 3.14: o OpenTimelineIO ainda não suporta o 3.14. Não há garantia de suporte ao 3.10/3.11. |
| **FFmpeg e FFprobe** | qualquer versão recente | versão atual | Os dois executáveis precisam estar no `PATH`. |
| **Git** | necessário | — | A dependência `clip` do `requirements.txt` é instalada via `git+https`. |
| **RAM** | 8 GB | 16 GB | Acervos grandes pedem mais. |
| **GPU** | não obrigatória | — | O processamento local roda em CPU. |
| **Navegador para títulos** | Edge ou Chrome instalado (Windows) | — | Em Linux/macOS ou Docker, instale o Chromium do Playwright (veja abaixo). |
| **Node.js** | só para rodar os autotestes de interface | — | Não é necessário para usar o programa. |

## Opção 1: Docker

O `Dockerfile` usa `python:3.12-slim-bookworm`, instala FFmpeg, PyTorch CPU, as dependências do `requirements.txt` e o Chromium do Playwright (usado nos títulos do render).

```bash
cp .env.example .env        # preencha as chaves (veja a seção do .env)
docker compose up -d --build
```

Abra **http://localhost:8000**. O `docker-compose.yml` monta três pastas do seu disco:

| Pasta local | Dentro do container | Conteúdo |
| :--- | :--- | :--- |
| `./src` | `/app/src` | Código-fonte, com recarregamento automático (`--reload`). |
| `./data` | `/app/data` | Banco SQLite, banco vetorial, proxies, caches, exportações e modelos. |
| `./watch` | `/app/watch` | Pasta monitorada de ingestão. |

> [!NOTE]
> A imagem base `slim` não traz o `git`, e o `requirements.txt` depende de um pacote instalado por `git+https`. Se o build falhar nessa linha, é isso. **A confirmar:** correção do Dockerfile pendente (item previsto em `docs/planos/ORDEM_DE_IMPLEMENTACAO.md`).

## Opção 2: instalação local

### Windows (PowerShell)

O atalho mais simples é o script que cria o ambiente e sobe o servidor:

```powershell
.\scripts\run-local.ps1
```

Ou passo a passo:

```powershell
git clone https://github.com/fernangcortes/capiau-talho-v03.git
cd capiau-talho-v03
uv venv .venv --python 3.12        # ou: py -3.12 -m venv .venv
uv pip install -r requirements.txt # ou: .venv\Scripts\pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python -m uvicorn src.api.server:app --reload
```

FFmpeg no Windows: `winget install Gyan.FFmpeg` (depois abra um terminal novo e teste `ffmpeg -version`).

### Linux / macOS

```bash
git clone https://github.com/fernangcortes/capiau-talho-v03.git
cd capiau-talho-v03
python3.12 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
python -m playwright install chromium     # navegador dos títulos no render
python -m uvicorn src.api.server:app --reload
```

FFmpeg: `sudo apt install -y ffmpeg` (Debian/Ubuntu) ou `brew install ffmpeg` (macOS).

### Navegador dos títulos (Titler)

O render de vídeo "fotografa" os títulos com um navegador headless (pacote `playwright`, já no `requirements.txt`). No Windows ele usa o Edge ou Chrome já instalado. Onde não há Edge/Chrome (Linux, macOS, Docker), rode `python -m playwright install chromium`. Sem navegador, o render sai sem títulos e o *preflight* avisa.

### Python 3.14

O `opentimelineio` não tem pacote para o Python 3.14. Se for o seu Python, crie um ambiente auxiliar 3.12 só para a exportação OTIO/XML/EDL (o programa o procura em `data/venv312`):

```powershell
uv venv data/venv312 --python 3.12
uv pip install --python data/venv312/Scripts/python.exe opentimelineio otio-fcp-adapter otio-cmx3600-adapter python-dotenv
```

Em Linux/macOS troque `Scripts/python.exe` por `bin/python`. **A confirmar:** o caminho padrão procurado pelo código aponta para `Scripts/python.exe`; em Linux/macOS pode ser preciso informar o Python do ambiente auxiliar nas Configurações (campo de Python do export).

### Atalhos e lançadores (somente Windows)

| Arquivo | Para que serve |
| :--- | :--- |
| `criar-atalho.bat` | Cria o atalho **CapIAu** na Área de Trabalho (chama `scripts\create_shortcut.ps1`). |
| `scripts/launch_capiau.ps1` e `scripts/launch_capiau.vbs` | Lançador sem janela de console: detecta se a porta 8000 já está ativa, se o Docker está disponível, ou sobe o servidor local. |
| `scripts/run-local.ps1` / `scripts/run-docker.ps1` | Sobem o servidor localmente ou via Docker. |
| `scripts/launch_detached.py` | Lança um processo desgrudado do console (evita o servidor morrer ao fechar o terminal). |

## Dependências opcionais

| Recurso | Instalação | Observações |
| :--- | :--- | :--- |
| **Denoise de áudio por IA local** (DPDFNet 48 kHz e GTCRN 16 kHz, via ONNX) | `pip install sherpa-onnx soundfile` e depois `python scripts/baixar_modelo_denoise.py` | Não vem instalado. Sem o pacote, o programa informa o que falta. `--verificar` só confere o modelo. |
| **Modelos NVIDIA (Canary, Nemotron) e SenseVoice** | Ambiente separado `.venv-nemo` com `requirements-nemo.txt` (comandos no cabeçalho do arquivo) | Recurso experimental. Outro local: variável `CAPIAU_VENV_NEMO`. |
| **Modelos locais (Sistema 1, ASR local, YOLO-World)** | Baixados em **Configurações > Modelos locais** | Experimentais. A transcrição local funciona, mas é lenta em máquinas fracas; a nuvem segue como caminho recomendado. |

## O arquivo `.env`

Copie `.env.example` para `.env`. O arquivo é ignorado pelo Git de propósito (contém segredos): **nunca faça commit dele**. Valores salvos no painel de configurações **têm prioridade** sobre o `.env`.

```env
# ── Chaves de API ────────────────────────────────────────────
OPENROUTER_API_KEY=          # essencial: visão, texto, temas, resumos e agente
ASSEMBLYAI_API_KEY=          # transcrição com diarização (padrão)
DEEPGRAM_API_KEY=            # transcrição alternativa (Nova-3)
AUPHONIC_API_KEY=            # tratamento de áudio na nuvem (também aceita no painel)
HF_TOKEN=                    # modelos locais restritos (ex.: diarização pyannote)
TYPESAFE_API_KEY=            # Sistema 1 em nuvem (Jev)
# Chaves diretas, se preferir não passar pelo OpenRouter:
# GEMINI_API_KEY=
# ANTHROPIC_API_KEY=
# DEEPSEEK_API_KEY=
# NVIDIA_NIM_KEY=

# ── Modelos ──────────────────────────────────────────────────
TEXT_MODEL=deepseek/deepseek-v4.1-flash
VISION_MODEL=google/gemini-2.5-flash
VISION_MODEL_FALLBACK=nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free
VISION_MAX_RETRIES=2
AGENT_MODEL=deepseek/deepseek-v4.1-flash
EMBEDDING_MODEL=sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2

# ── Desempenho ───────────────────────────────────────────────
MAX_CONVERSION_WORKERS=2     # conversões de proxy em paralelo

# ── Pastas (opcionais; padrões abaixo) ───────────────────────
# CAPIAU_WATCH=watch
# CAPIAU_DB_PATH=data/capiau.db
# CAPIAU_ORIGINALS=data/originals
# CAPIAU_PROXIES=data/proxies
# CAPIAU_CACHE=data/cache
# CAPIAU_EXPORTS_DIR=data/exports
# CAPIAU_QDRANT_DB=data/qdrant.db

# ── S3 (opcional) ────────────────────────────────────────────
USE_S3_STORAGE=false
# AWS_ACCESS_KEY_ID=
# AWS_SECRET_ACCESS_KEY=
# AWS_REGION=us-east-1
# AWS_S3_BUCKET=capiau-talho-storage

# ── Reconhecimento facial em nuvem (opcional) ────────────────
# AZURE_FACE_ENDPOINT=
# AZURE_FACE_KEY=
```

Sem `OPENROUTER_API_KEY`, descrição visual, temas, resumos e o agente de edição não funcionam. A busca semântica, os embeddings CLIP e a biometria facial rodam localmente.

### Modelos gratuitos (`:free`) do OpenRouter

Conforme o OpenRouter em out/2026: limite de 20 requisições por minuto; 1000 por dia somente se a conta já acumulou US$ 10 em créditos, senão 50 por dia. Em lotes grandes eles também falham com timeout (504) sob carga. Por isso o padrão de visão é pago (Gemini) e o gratuito (Nemotron) fica apenas como reserva. Veja [[16. Solução de Problemas e FAQ|16.-Solucao-de-Problemas-e-FAQ]].

## Executando

Com o ambiente ativo, na raiz do projeto:

```bash
uvicorn src.api.server:app --host 127.0.0.1 --port 8000 --reload
```

Abra **http://localhost:8000**. A documentação interativa da API fica em **http://localhost:8000/docs**. O indicador no cabeçalho da interface mostra a saúde do sistema (rota `/api/health`).

Para trocar a porta, use `--port 8080`.
