# 16. Solução de Problemas e FAQ

Nesta seção você encontra soluções rápidas para as dúvidas mais frequentes e problemas operacionais comuns no **CapIAu-Talho**.

---

## 🩺 Diagnóstico Rápido de Problemas

### 1. "FFmpeg ou FFprobe não encontrado"
- **Sintoma:** O sistema não gera proxies ou acusa erro na ingestão de mídias.
- **Causa:** O executável do FFmpeg não está adicionado à variável de ambiente `PATH` do sistema.
- **Solução:**
  - **No Windows:** Abra o PowerShell como Administrador e execute `winget install Gyan.FFmpeg`. Reinicie o terminal.
  - **No Linux:** Execute `sudo apt update && sudo apt install -y ffmpeg`.
  - Teste digitando `ffmpeg -version` no terminal.

---

### 2. "Erro de Chave de API na Transcrição (AssemblyAI / OpenAI / Groq)"
- **Sintoma:** A transcrição falha com erro 401 ou mensagem de chave ausente.
- **Solução:**
  1. Verifique se o arquivo `.env` existe na raiz do projeto (e não apenas o `.env.example`).
  2. Abra o `.env` e confirme se a linha `ASSEMBLYAI_API_KEY=sua_chave` ou `GROQ_API_KEY=sua_chave` não contém aspas extras ou espaços no final.
  3. Caso queira rodar 100% offline sem custos, altere no `.env`: `TRANSCRIPTION_PROVIDER=whisper_local`.

---

### 3. "Porta 8000 já está em uso"
- **Sintoma:** O comando Uvicorn falha com erro `[Errno 10048] error while attempting to bind on address ('127.0.0.1', 8000)`.
- **Solução:**
  - Inicie o servidor em outra porta: `uvicorn src.api.main:app --port 8080 --reload`.
  - Ou encerre o processo anterior no Windows: `Get-Process python | Stop-Process`.

---

### 4. "O Kdenlive não abre o arquivo .otio"
- **Sintoma:** O Kdenlive reporta formato desconhecido ao tentar abrir o arquivo de exportação.
- **Solução:**
  - O suporte nativo ao OpenTimelineIO está disponível a partir do **Kdenlive versão 25.04+**. Atualize seu Kdenlive para a versão mais recente.
  - Para versões anteriores do Kdenlive ou Premiere Pro, exporte no formato **Final Cut Pro 7 XML (.xml)**.

---

### 5. "Alto uso de memória RAM ao importar centenas de fotos RAW (.CR2)"
- **Sintoma:** A máquina fica lenta durante a geração de miniaturas de fotos em resolução muito alta.
- **Solução:**
  - O Talho processa imagens em lotes (chunks). Você pode limitar o número de workers simultâneos no `.env` adicionando `MAX_WORKERS=2` para reduzir a carga na CPU e economizar memória.

---

## ❓ Perguntas Frequentes (FAQ)

### O CapIAu-Talho funciona completamente offline?
**Sim.** Se você configurar o `.env` com `TRANSCRIPTION_PROVIDER=whisper_local` e utilizar os modelos locais de CLIP e InsightFace ONNX, o sistema operará 100% offline sem enviar um único byte para a internet.

### Meus arquivos originais de vídeo são alterados ou sobrescritos?
**Não, nunca.** O Talho opera no modo **Read-Only** sobre seus arquivos brutos originais. Todas as alterações, cortes, tags e proxies são gravados isoladamente dentro da pasta `data/` e no banco de dados `data/capiau.db`.

### Onde ficam armazenados os logs e como posso inspecioná-los?
Os logs detalhados de execução são gravados na pasta `logs/` na raiz do projeto (`logs/app.log` e `logs/workers.log`), além de serem exibidos em tempo real na aba de Tarefas da interface web.

### Como faço backup de um projeto?
Basta copiar os arquivos:
1. `data/capiau.db` (Banco de dados relacional SQLite com todos os cortes, transcrições e projetos).
2. Pasta `data/chroma/` (Bancos vetoriais de busca semântica).
3. Seu arquivo `.env` com suas chaves de configuração.
