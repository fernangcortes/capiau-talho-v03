# 14. Guia Completo de Atalhos e Perfis NLE

O **CapIAu-Talho** conta com um motor completo de atalhos de teclado e compatibilidade com perfis NLE de mercado, permitindo que editores operem o sistema com a ergonomia de seu software preferido ou personalizem comandos livremente.

---

## 🎛️ 1. Perfis NLE Suportados de Fábrica

No modal de atalhos (<kbd>⌨️</kbd> na barra de ferramentas da timeline), selecione o perfil ativo no menu superior:

| Perfil NLE | Foco & Filosofia | Atalhos Notáveis |
| :--- | :--- | :--- |
| 🎬 **CapIAu Padrão** | Híbrido moderno ultrarrápido para montagem documental e corte inteligente. | `Z` Split, `V` Seleção, `T` Faixa, `Q`/`W` Ripple Trims, `S` Snapping, `M` Marcador, `A` Alternativas IA. |
| 🐧 **Kdenlive** | Padrão consagrado da comunidade Open Source e Linux. | `Shift+R` / `X` Split Razor, `S` Seleção, `M` Espaçador, `V` Inserção, `F10` Snapping, `J`/`K`/`L` Shuttle. |
| 🟣 **Adobe Premiere Pro** | Ergonomia clássica da Creative Cloud. | `Ctrl+K` / `C` Razor, `A` / `Shift+A` Seleção de Trilha, `V` Seleção, `S` Snapping, `Q`/`W` Ripple Trims. |
| 🟡 **DaVinci Resolve** | Padrão profissional Blackmagic Design para ilhas de pós. | `Ctrl+\` / `B` Blade, `A` Seleção, `N` Snapping, `Shift+Backspace` Ripple Delete, `Alt+[` / `Alt+]` Trims. |
| 🍏 **Apple Final Cut Pro** | Ergonomia magnética para edição não-destrutiva ágil. | `Cmd+B` / `B` Blade, `A` Seleção, `N` Snapping, `E` Append, `Shift+Delete` Ripple Delete. |

## ⌨️ 2. Teclado Visual Esquemático 1:1 & Live Testing HUD

O sistema integra um simulador de teclado mecânico (ANSI TKL) em tamanho real diretamente no modal de ajuda:

* **Keycaps Proporcionais Responsivos:** Exibem o caractere da tecla e um ponto indicador colorido mapeado para a categoria da ação NLE (Reprodução, Ferramentas, Cortes, Marcadores, IA).
* **Destaque Bidirecional:** Passar o mouse sobre qualquer tecla no teclado virtual ilumina instantaneamente a linha correspondente nas 3 colunas esquemáticas do manual; passar o mouse no manual ilumina a tecla no teclado virtual.
* **Camadas de Modificadores:** Botões de alternância rápida para inspecionar comandos em `Padrão`, `+ Shift`, `+ Ctrl` e `+ Alt` (com transição em tempo real ao segurar os modificadores no teclado físico).
* **Live Testing HUD:** Digite qualquer atalho físico para vê-lo pulsar na tela em neon e inspecionar sua função sem fechar o modal.
* **Modo Tela Cheia (Fullscreen):** Alternância entre janela ampla e `100vw × 100vh` para visibilidade total em qualquer resolução.

## 🎬 3. Navegação do Player & Shuttle (Source e Program)

| Tecla / Combinação | Ação | Descrição |
| :--- | :--- | :--- |
| **`Espaço`** | **Play / Pause Geral** | Alterna entre tocar e pausar no monitor em foco. |
| **`J`** | **Shuttle Reverso** | Pressione consecutivamente para acelerar (-1x, -2x, -4x, -8x). |
| **`K`** | **Shuttle Parar** | Pausa a reprodução imediata. |
| **`L`** | **Shuttle Avanço** | Pressione consecutivamente para acelerar (1.5x, 2x, 4x, 8x). |
| **`K + J` / `K + L`** | **Jog Frame a Frame** | Recua ou avança exatamente 1 frame mantendo K pressionado. |
| **`←` / `→`** | **Navegar 1 Frame** | Retrocede ou avança 1 frame para cortes de precisão. |
| **`↑` / `↓`** | **Saltar Pontos de Corte** | **Na Timeline:** Move a agulha para o corte anterior (↑) ou próximo (↓).<br>**No Source:** Pula para o ponto In (↑) ou Out (↓). |
| **`Duplo Clique`** | **Maximizar Player** | Expande o monitor ativo para tela cheia. |

## ✂️ 4. Marcação de Pontos, Inserção e Edição na Timeline

| Tecla / Combinação | Ação | Descrição |
| :--- | :--- | :--- |
| **`I` / `O`** | **Marcar In / Out** | Define o início e o fim do trecho selecionado no Source. |
| **`Alt + X`** | **Limpar In / Out** | Remove as marcações de entrada e saída ativas. |
| **`E`** | **Adicionar à Timeline (Append)** | Envia o trecho marcado [In-Out] para a timeline na posição da agulha. |
| **`Shift + E`** | **Corte Direto de Fala** | Insere o diálogo selecionado na transcrição diretamente na trilha V1/A1. |
| **`Z`** *(ou `Shift+R`/`Ctrl+K`/`B`)* | **Dividir Clipe (Split)** | Corta o clipe na agulha de reprodução. Se vinculado, divide vídeo e áudio juntos. |
| **`Q`** | **Ripple Delete até a Agulha (Head)** | Corta do início do clipe até a agulha e fecha o espaço puxando os clipes seguintes. |
| **`W`** | **Ripple Delete da Agulha ao Fim (Tail)** | Corta da agulha até o fim do clipe e fecha o espaço puxando os clipes seguintes. |
| **`Delete` / `Backspace`** | **Lift Delete / Deletar Gap / Ghost** | **Em clipe:** Apaga o clipe mantendo o espaço vazio.<br>**Em Gap:** Fecha o espaço vazio.<br>**Em Ghost:** Rejeita sugestão de IA. |
| **`Shift + Delete`** | **Ripple Delete de Clipe** | Apaga o clipe selecionado e une os blocos vizinhos imediatamente. |
| **`U`** | **Desvincular / Vincular Par A/V** | Desvincula o par áudio/vídeo do clipe para possibilitar cortes L-Cut e J-Cut. |

## 🎛️ 5. Ferramentas da Timeline e Ajustes de Precisão

| Tecla / Combinação | Ação | Descrição |
| :--- | :--- | :--- |
| **`V`** | **Ferramenta de Seleção** | Retorna ao cursor padrão de seleção e arraste. |
| **`T` / `Shift + T`** | **Selecionar Faixa para Frente / Trás** | Seleciona todos os clipes à direita ou esquerda em todas as faixas (*Shift = 1 faixa*). |
| **`S`** *(ou `F10` / `N`)* | **Alternar Snapping Magnético** | Liga ou desliga o magnetismo da timeline com guias visuais no Canvas. |
| **`←` / `→`** | **Deslocar Clipe (Nudge 1 Frame)** | Desloca o clipe selecionado 1 frame para a esquerda ou direita. |
| **`Alt + ←` / `Alt + →`** | **Ajustar Ponto IN (Trim In)** | Recua ou avança a borda esquerda do clipe selecionado em 1 frame. |
| **`Shift + ←` / `Shift + →`** | **Ajustar Ponto OUT (Trim Out)** | Recua ou avança a borda direita do clipe selecionado em 1 frame. |
| **`[` / `]`** | **Nudge Trim Rápido** | Ajusta borda esquerda (`[`) ou borda direita (`]`) em 1 frame. |

## 📍 6. Marcadores e Inteligência Artificial

| Tecla / Combinação | Ação | Descrição |
| :--- | :--- | :--- |
| **`M`** | **Adicionar / Editar Marcador** | Cria ou edita marcador na agulha sem interromper a reprodução. |
| **`Shift + M` / `Alt + M`** | **Navegar Marcadores** | Pula para o próximo ou anterior marcador da timeline. |
| **`Shift + Clique`** | **Seleção Múltipla** | Seleciona vários marcadores simultaneamente para edição ou exclusão em lote. |
| **`A`** | **Alternativas IA / Inspetor** | **Na Timeline:** Abre o carrossel de planos alternativos sugeridos pela IA.<br>**Na Biblioteca:** Abre o Inspetor de Metadados. |
| **`Enter` / `Y`** | **Aceitar Sugestão de IA** | Aceita e consolida o clipe fantasma (*ghost clip*) na timeline. |
| **`Ctrl + S`** | **Salvar Timeline / Projeto** | Salva a timeline ativa no banco de dados. |
| **`Ctrl + Z` / `Ctrl + Y`** | **Desfazer / Refazer** | Histórico de edição não-destrutivo. |
| **`Esc`** | **Fechar / Cancelar** | Fecha gavetas, modais e cancela seleções ativas. |
