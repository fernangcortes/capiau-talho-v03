# 14. Guia Completo de Atalhos

O **CapIAu-Talho** foi desenhado para ser operado inteiramente pelo teclado por editores profissionais acostumados com a ergonomia de NLEs como Premiere, Resolve e Avid.

---

## 🎬 Navegação do Player (Padrão NLE JKL)

Os atalhos abaixo controlam o monitor ativo (**Source** ou **Program**):

| Tecla | Ação | Descrição |
| :---: | :--- | :--- |
| **`J`** | **Retroceder Vídeo** | Pressione repetidamente para acelerar o retrocesso (-1x, -2x, -4x, -8x). |
| **`K`** | **Pausar / Parar** | Pausa a reprodução ou restaura a velocidade normal de 1x. |
| **`L`** | **Avançar Vídeo** | Pressione repetidamente para acelerar o avanço (1.5x, 2x, 4x, 8x). |
| **`Espaço`** | **Play / Pause Geral** | Alterna entre tocar e pausar no monitor em foco. |
| **`←` / `→`** | **Navegar Quadro a Quadro** | Retrocede ou avança exatamente **1 frame** do vídeo para cortes cirúrgicos. |
| **`↑` / `↓`** | **Saltar Pontos de Corte** | **Na Timeline:** Move a agulha para o início/fim do clipe anterior (↑) ou próximo (↓).<br>**No Source:** Pula para o ponto In (↑) ou Out (↓). |
| **`Duplo Clique`** | **Maximizar Player** | Expande o monitor ativo para tela cheia. |

---

## ✂️ Marcação de Pontos e Inserção na Timeline

| Tecla | Ação | Descrição |
| :---: | :--- | :--- |
| **`I`** | **Marcar Entrada (In)** | Define o frame inicial do trecho a ser recortado do Source. |
| **`O`** | **Marcar Saída (Out)** | Define o frame final do trecho a ser recortado do Source. |
| **`E`** | **Inserir na Timeline** | Envia o trecho marcado [In-Out] para a timeline na posição da agulha. |
| **`Shift + E`** | **Corte Direto de Fala** | Insere o texto selecionado no painel de transcrição diretamente na timeline nas pistas V1 e A1. |
| **`Alt + I` / `Alt + O`** | **Limpar In / Out** | Remove a marcação de entrada ou saída do clipe. |

---

## 🎛️ Ferramentas da Timeline

| Tecla | Ferramenta | Descrição |
| :---: | :--- | :--- |
| **`V`** | **Seleção (Selection)** | Ferramenta padrão para selecionar, mover e redimensionar blocos. |
| **`C`** | **Gilete (Razor)** | Corta o clipe selecionado na posição atual da agulha de reprodução. |
| **`B`** | **Ripple Edit** | Encurta ou estica o clipe deslocando todos os clipes subsequentes. |
| **`N`** | **Roll Edit** | Ajusta o ponto de transição entre dois clipes contíguos sem alterar a duração total. |
| **`Y`** | **Slip Tool** | Altera os pontos In/Out internos do clipe mantendo a duração física na timeline. |
| **`U`** | **Slide Tool** | Move a posição do clipe na timeline reajustando os clipes vizinhos. |
| **`S`** | **Magnetismo (Snap)** | Ativa ou desativa a atração magnética de clipes e agulha. |
| **`M`** | **Marcador (Marker)** | Adiciona um marcador de timecode colorido na timeline. |
| **`Shift + Delete`** | **Fechar Gap (Ripple Delete)** | Remove o espaço vazio entre dois clipes unindo-os imediatamente. |

## 🤖 Comandos de Inteligência Artificial e Alternativas

| Tecla | Contexto | Ação |
| :---: | :--- | :--- |
| **`A`** | **Na Timeline** | **Carrossel de Alternativas:** Abre uma janela flutuante com planos alternativos sugeridos pela IA para substituir o clipe selecionado. |
| **`A`** | **Na Biblioteca** | **Auto-Análise:** Dispara a análise profunda de IA (visão e transcrição) para a mídia selecionada. |
| **`Ctrl + F`** | **Global** | Foca na barra de busca semântica híbrida. |

---

## 🖥️ Comandos Globais de Sistema

| Tecla | Ação |
| :---: | :--- |
| **`Ctrl + S`** | Salva o projeto e persiste alterações no banco de dados. |
| **`Ctrl + Z`** | Desfaz a última ação de edição. |
| **`Ctrl + Y`** / **`Ctrl + Shift + Z`** | Refaz a última ação desfeita. |
| **`Esc`** | Fecha gavetas, caixas de diálogo, modais de desambiguação e cancela seleções. |
