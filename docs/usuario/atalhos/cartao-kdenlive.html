Quando o mesmo atalho aparece em mais de uma ação, o resultado depende do contexto (painel em foco, ferramenta ativa, elemento sob o mouse, sugestão ativa).

1. Reprodução & Navegação

  • EspaçoPlay / Pause

  • KShuttle Play / Pause (K)
  • LShuttle Avanço (L)
  • Shift + →Shuttle Acelerado / Avanço Rápido (Shift + →)
  • Shift + ←Shuttle Acelerado / Recuo Rápido (Shift + ←)
  • Ctrl + →Câmera Lenta Avanço (Ctrl + →)
  • Ctrl + ←Câmera Lenta Recuo (Ctrl + ←)
  • K + J ou ←Jog Recuar 1 Frame (K + J)
  • ←Navegar 1 Frame para Trás
  • K + L ou →Jog Avançar 1 Frame (K + L)
  • →Navegar 1 Frame para Frente
  • IMarcar Ponto de Entrada (IN)
  • OMarcar Ponto de Saída (OUT)
  • Ctrl + Shift + I ou Alt + ILimpar Ponto IN
  • Ctrl + Shift + O ou Alt + OLimpar Ponto OUT
  • Alt + X ou Ctrl + Shift + ALimpar Pontos IN e OUT
  • XMarcar Clipe (IN / OUT)
  • Shift + IIr para o Ponto IN
  • Shift + OIr para o Ponto OUT
  • Shift + EspaçoTocar de IN até OUT
  • Ctrl + Shift + Espaço ou Ctrl + LAlternar Reprodução em Loop
  • EInserir na Timeline (Append)
  • Alt + ← ou ↑Pular para Ponto Anterior / Início
  • Alt + → ou ↓Pular para Próximo Ponto / Fim
  • Ctrl + GIr para Timecode / Navegação Numérica
