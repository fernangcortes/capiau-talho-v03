# Fontes da interface

Empacotadas para a UI funcionar offline. Todas sob a **SIL Open Font License 1.1** (https://openfontlicense.org),
que permite uso, embutir e redistribuir junto com software.

| Arquivo | Família | Autor |
|---|---|---|
| `inter-var.woff2` | Inter (variável 100–900) | Rasmus Andersson |
| `outfit-var.woff2` | Outfit (variável 100–900) | On Brand Investments |
| `roboto-flex-var.woff2` | Roboto Flex (variável, eixo de peso) | Google / Font Bureau |
| `plex-sans-condensed-*.woff2` | IBM Plex Sans Condensed 300–700 | IBM |
| `barlow-semi-condensed-*.woff2` | Barlow Semi Condensed 300–700 | Jeremy Tribby |

Origem: pacotes Fontsource (espelho do Google Fonts) via cdn.jsdelivr.net, subconjunto `latin`, baixados em 28/09/2026.
Declarações em `fonts.css`. Escolha da fonte: Configurações → Aparência (`ui.font_family`).
